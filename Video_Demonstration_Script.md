# Video Demonstration Script (3–5 minutes)

**1. Introduce the app (User Interface)**

"This is the Chef's Menu Manager app. It has a title at the top, and a form below it where the chef can enter a new menu item, followed by a list showing all menu items that have been added."

*(Scroll slowly from top to bottom so the title, form, and empty list are visible.)*

"Right now, no menu items have been added, so the app displays a message letting the chef know the list is empty."

---

**2. Show validation**

"Before adding an item, let's see what happens if I try to submit the form empty."

*(Tap "Add Menu Item" without filling in anything.)*

"The app shows error messages under each required field — Dish Name, Description, and Price — telling the chef what still needs to be filled in."

*(Optional: type a non-numeric value into Price, e.g. "abc", and tap Add again to show the "valid price" error.)*

---

**3. Enter menu information**

"Now let's add a real menu item."

*(Type into Dish Name, e.g. "Grilled Salmon".)*

"I'll enter the dish name..."

*(Type into Description, e.g. "Fresh salmon fillet grilled with lemon butter sauce.")*

"...a description..."

*(Tap the Course picker and select a course, e.g. "Main Course".)*

"...select the course, using the picker with Starter, Main Course, and Dessert..."

*(Type into Price, e.g. "185".)*

"...and the price."

---

**4. Successfully add the item**

*(Tap "Add Menu Item".)*

"When I tap 'Add Menu Item', I get a confirmation message telling me the item was added successfully."

*(Dismiss the alert.)*

"And the form clears, ready for the next item."

---

**5. Display menu items**

"Below the form, the new item now appears in the list, showing the dish name, price, course, and description."

*(Scroll down to show the new card in the list.)*

"Let's add one more item to show the list updates automatically."

*(Repeat step 3–4 quickly with a second item, e.g. "Bruschetta" / Starter / 65.)*

"As you can see, the list updates immediately and now shows both menu items, without needing to refresh anything."

---

**6. Wrap up**

"That covers the core features of Part 2: a clean, consistent user interface, capturing menu information, displaying menu items as they're added, and a user-friendly experience with validation, error messages, and confirmation feedback."

*(End recording.)*
